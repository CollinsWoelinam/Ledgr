# Installing Ledgr

Ledgr isn't in the Play Store yet, so it's installed from an APK file. This takes about two minutes. You need an Android phone running Android 7 or newer, with MTN MoMo or Telecel Cash.

## 1. Get the file

Download `ledgr-<version>.apk` from the [Releases page](https://github.com/CollinsWoelinam/Ledgr/releases), or from whoever sent it to you. Only install Ledgr from these places: a copy from anywhere else could be a fake that reads your SMS.

## 2. Install it

1. Open the downloaded file (from your notifications, or **My Files › Downloads**).
2. If Android says your browser or file manager **isn't allowed to install unknown apps**, tap **Settings**, turn on **Allow from this source**, and go back.
3. Tap **Install**.
4. **Play Protect** may warn that it doesn't recognise the app, because Ledgr isn't from the Play Store and reads SMS. Tap **More details › Install anyway**.

## 3. Allow SMS access

Open Ledgr and tap **Get started**. When Android asks, allow Ledgr to **send and view SMS messages**. It only ever reads messages from MoMo and Telecel Cash.

**If SMS access is greyed out or blocked** (newer Android versions protect it for apps installed from a file):

1. Go to **Settings › Apps › Ledgr**.
2. Tap **⋮** (top right) › **Allow restricted settings**, and confirm with your PIN or fingerprint.
3. Go back to Ledgr and allow SMS access again.

Ledgr then reads your wallet history, which takes a few seconds, and you're in.

## 4. Optional, but worth it

- **Notifications:** allow them for budget alerts and the Sunday summary.
- **Battery:** on Samsung phones, make sure Ledgr isn't in **Settings › Battery › Background usage limits › Sleeping apps**, so alerts can arrive while it's closed.
- **App lock:** turn it on in Ledgr's Settings to use your fingerprint.

## Updating

Install the new APK over the old one, the same way. Your data stays. (Android only accepts an update signed by the same developer, so a fake "update" can't replace Ledgr.)

## If something's wrong

In Ledgr, **Settings › Send feedback** opens a report on GitHub, with your Ledgr and Android versions filled in. A wallet message Ledgr couldn't read waits in **Needs review**: say which kind of message it was, but **don't paste the SMS itself**, since it contains your names, numbers and balance.
